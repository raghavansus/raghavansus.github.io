PROJECT CASE STUDY

Guidewire Navigation Simulation

A SOFA-based simulation environment built as the output device for the endovascular testbed, in lieu of a physical slave mechanism.

ADD HERO IMAGE / SIMULATION

Context & objective

Running human-factors studies on a fully physical master–slave platform is slow to iterate on and hard to scale across many participants and target configurations. The objective was to build a simulated vessel environment that could stand in for the physical output device on the Remote Endovascular Surgery Testbed — modeling guidewire and catheter behavior realistically enough to support real human-subject testing.

My contribution

  • Built a SOFA-based simulation environment modeling guidewire/catheter translation, rotation, and vessel interaction.
  • Integrated the simulation with the master-side controls of the endovascular testbed so it functions as a drop-in replacement for the physical output device.
  • Structured the environment to support the target configurations and scaling conditions used in the motion-scaling human-factors study.

Design & process

Using the SOFA physics framework, I modeled vessel geometry and guidewire/catheter interaction so the simulated instrument responds to master-side input the same way the physical slave mechanism would — translation, rotation, and contact with vessel walls. Connecting it to the same master controls as the physical testbed meant the human-factors study could run entirely in simulation without changing the operator's experience at the input device.

Results & impact

This simulation environment is the system currently being used to conduct the Motion Scaling Study — all 16 participants navigate to targets in the simulated vessel across all 4 scaling conditions, rather than on physical hardware, making the study far easier to run and repeat.

Reflection

Building the simulation forced me to think carefully about which aspects of physical guidewire/vessel interaction actually matter for the study's outcome measures versus which are cosmetic. The next step is layering in force feedback, so the simulated vessel can drive the haptic system prototyped in Catheter Manipulation Hardware.
