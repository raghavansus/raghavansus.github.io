# Raghavan Ramaswamy — Engineering Portfolio

Static portfolio site for GitHub Pages.

## Before publishing
1. Replace the About placeholder text in `index.html`.
2. Add your email, LinkedIn, and GitHub URLs.
3. Put your one-page resume at `assets/resume.pdf`.
4. Fill in the four project pages under `projects/`.
5. Add project images to `assets/` and replace the placeholder blocks with `<img>` elements.

## Local preview
Open `index.html` in a browser, or use VS Code Live Server.
